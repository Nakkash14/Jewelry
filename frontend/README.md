# Frontend

Vite 8 + React jewelry storefront. Work from this `frontend/` directory.

## Scripts

### `npm start` / `npm run dev`

Starts the Vite dev server at [http://localhost:3000](http://localhost:3000).

### `npm test`

Runs Vitest.

### `npm run build`

Production build to `dist/`.

### `npm run preview`

Serves the production build at [http://localhost:3000](http://localhost:3000).
